# Instruções do projeto — IoT StressBed

## Git: nunca aparecer como coautor

Commits neste repositório devem ter **apenas o nome do usuário como autor**.
Nunca adicione `Co-Authored-By: Claude` (ou qualquer variante) nas mensagens de
commit, mesmo quando o commit for feito por um subagente delegado. Isso vale
para todos os agentes e subagentes trabalhando neste repositório.
